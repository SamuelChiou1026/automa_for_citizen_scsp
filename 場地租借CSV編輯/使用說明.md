## 一、這兩個程式在解決什麼問題？

在「社宅雲」網站上租借社宅的公共空間（例如多功能空間），每一筆都要：登入台北通 → 找場地 → 按「我要租借」→ 同意規約 → 填一整張表單 → 送出。
如果一次要申請十幾、二十筆，手動一筆一筆填非常耗時，也容易填錯。

這套工具把工作拆成兩步：

| 程式 | 白話說明 |
| --- | --- |
| **場地租借CSV編輯.html** | 「填單小幫手」。在一個表格裡把要租的場地、日期、時段等資料一次填好，並幫你檢查有沒有填錯，最後存成一個 CSV 檔。 |
| **社宅場地租借.automa.json** | 「自動申請機器人」。讀取上一步存好的 CSV 檔，自動登入社宅雲，一筆一筆幫你填表、送出申請，最後告訴你哪幾筆成功、哪幾筆失敗。 |

簡單說：**先用 HTML 填資料 → 再讓機器人幫你送出申請。**

```mermaid
flowchart LR
    A[打開 HTML 填寫資料] --> B[匯出 CSV 檔]
    B --> C[在 Automa 執行機器人]
    C --> D[自動登入並逐筆送出申請]
    D --> E[顯示成功/失敗清單]
```

## 二、事前準備（只需做一次）

1. **電腦**：Windows 或 Mac 都可以。
2. **瀏覽器**：建議使用 **Google Chrome**（或 Microsoft Edge）。
3. **安裝 Automa 擴充功能**：到 Chrome 線上應用程式商店搜尋「Automa」並安裝。
4. **開啟檔案存取權限**（很重要，沒開機器人會讀不到 CSV）：
   - 在網址列輸入 `chrome://extensions` 並按 Enter。
   - 找到 Automa，按「詳細資料」。
   - 打開「**允許存取檔案網址**」。
5. **匯入機器人流程**：打開 Automa → 工作流程（Workflows）→ 匯入（Import）→ 選擇 `社宅場地租借.automa.json`。
6. **確認登入帳號**：機器人會用流程裡設定好的台北通帳號密碼登入。若要改成你自己的帳號，請在 Automa 裡打開這個流程，修改「輸入帳號」「輸入密碼」兩個方塊。

> 提醒：流程檔裡直接存有帳號密碼，請勿把 `社宅場地租借.automa.json` 隨意轉傳給不相關的人。

## 三、步驟一：用「場地租借CSV編輯.html」填資料

### 打開方式
直接**雙擊** `場地租借CSV編輯.html`，會用瀏覽器開啟。不用安裝任何東西，也不用連網。

### 畫面上的按鈕

| 按鈕 | 作用 |
| --- | --- |
| 新增一列 | 在表格最下面加一筆空白資料 |
| 匯入 CSV | 把之前存過的 CSV 檔讀回來繼續編輯（會**取代**目前表格內容） |
| 匯出 CSV | 檢查資料無誤後，存成 CSV 檔 |
| 清空表格 | 清除全部資料（會先問你確定嗎） |
| 每列的「複製」 | 在下方複製一筆一模一樣的資料，適合「同場地、不同日期」 |
| 每列的「刪除」 | 刪掉這一筆（至少會保留一列） |

### 每個欄位怎麼填

| 欄位 | 填法 |
| --- | --- |
| 場地名稱 | 從下拉選單選（多功能空間1、2、3、5） |
| 信箱 | 接收通知的 Email，例如 `name@example.com` |
| 租用日期 | 輸入 **8 碼數字**，例如 `20261130`（打其他符號會自動被去掉） |
| 租用時段 | 從下拉選單選（08:30-12:30、13:00-17:00、18:00-22:00） |
| 人數 | 填數字 |
| 申請單位及負責人名稱 | 例如「青創協會 王小明」 |
| 活動名稱 | 活動的名稱 |
| 活動編號 | 有就填，沒有可空白 |

### 重要規則：日期必須在 15 天之後
社宅雲**只接受使用日兩週前**提出的申請。所以租用日期必須比今天晚 **16 天以上**。
填太早的日期會跳出提醒：「社宅雲僅接受使用日前兩週提出的線上申請」，畫面上方也會寫出「最早可選」的日期。

### 匯出 CSV
1. 按「**匯出 CSV**」。
2. 若有填錯（例如信箱格式錯、日期太早），會跳出清單告訴你「第幾列、哪個欄位、什麼問題」，改好再按一次。
3. 沒問題時：
   - Chrome / Edge：會跳出存檔視窗，選擇要存在哪裡。
   - Safari 等其他瀏覽器：會直接存到「下載」資料夾。
4. 檔名會長得像 `場地租借_20261018_153000.csv`。**請記住存放位置**，下一步要用。

### 小貼心
- 資料會**自動保存**在這台電腦的瀏覽器裡，關掉再打開資料還在。
- 但換電腦或換瀏覽器就看不到，重要資料請記得匯出 CSV 保存。

## 四、步驟二：用 Automa 機器人自動送出申請

1. 打開 Chrome，點右上角的 Automa 圖示，找到「**社宅場地租借**」流程，按 **執行（▶）**。
2. 會跳出一個視窗：「請輸入你的csv檔案路徑含副檔名」。
   輸入剛剛匯出的 CSV 檔完整路徑，例如：
   - Windows：`C:\Users\你的名字\Downloads\場地租借_20261018_153000.csv`
   - Mac：`/Users/你的名字/Downloads/場地租借_20261018_153000.csv`

   > 小技巧（Windows）：在檔案總管對檔案按住 Shift + 右鍵 →「複製路徑」，再貼上即可（前後的引號會自動去掉）。
3. 接著機器人會自己完成以下動作，**過程中請不要操作那個瀏覽器視窗**：
   - 開啟社宅雲 → 用台北通登入
   - 進入場地列表
   - 每一筆資料依序：點選場地 → 我要租借 → 同意規約 → 填寫表單 → 送出申請
4. 表單中以下項目會自動幫你選好：
   - 使用單位：**青創**
   - 冷氣：**是**（場地有冷氣時）
   - 是否為公益性質：**是**，類別「**配合機關主辦之活動**」
5. 執行時，網頁右上角會出現「**社宅場地租借 執行紀錄**」小視窗，即時顯示目前跑到第幾筆、哪筆成功（綠色）、哪筆失敗（紅色）。

### 執行完成後
- 會跳出統計訊息，例如「執行完成：成功 8 筆，失敗 2 筆」。
- 失敗的那幾筆會寫出原因（例如「租用時段不在可選時段內」、「場地列表找不到某場地」）。
- 可按「**複製失敗清單**」，貼到 Excel 或 LINE 方便後續**人工補申請**。
- 某一筆失敗不會中斷整個流程，機器人會自動跳過，繼續處理下一筆。

## 五、常見問題

| 狀況 | 怎麼辦 |
| --- | --- |
| 機器人說「讀取檔案失敗」 | 檢查路徑有沒有打錯、檔名有沒有含 `.csv`，以及 Automa 是否已開啟「允許存取檔案網址」。 |
| 機器人說「標題列缺少欄位」 | 請用 HTML 工具匯出的 CSV，不要用 Excel 另存造成格式跑掉。 |
| 某筆顯示「送出後未確認成功，可能已送出」 | 網站反應較慢，請到社宅雲的「空間租借紀錄」確認是否已申請，避免重複送出。 |
| 某筆顯示「沒有可選的租用時段」 | 該日期時段可能已被別人借走或尚未開放，請換日期或時段。 |
| HTML 打開後資料不見了 | 可能換了瀏覽器或清除了瀏覽紀錄。用「匯入 CSV」把之前匯出的檔案讀回來即可。 |
| 想改信箱、日期後重跑失敗的幾筆 | 在 HTML 裡只保留失敗的那幾筆，修正後重新匯出，再執行一次機器人。 |

## 六、一句話總結

1. **雙擊 HTML** → 填好表格 → **匯出 CSV**
2. **Chrome 執行 Automa 流程** → 貼上 CSV 路徑 → 等機器人跑完
3. 看結果，**失敗的人工補上**即可
